# SpringBot Realtime

This version includes:
- moderation
- utility
- writing help
- empathy
- fun commands
- news feeds
- information commands
- study commands using the included chapter review notes
- voice playback through stable stream/radio commands

Music that works on Railway:
- !radio lofi
- !radio jazz
- !radio classical
- !radio news
- !stream <direct_audio_url>
- !queueadd <direct_audio_url>

Real-time style features:
- live RSS news commands
- live web summary lookups via Wikipedia REST
- live dictionary lookups if a Merriam-Webster key is added

Study commands:
- !chapters
- !chapter 1
- !studysearch dns
